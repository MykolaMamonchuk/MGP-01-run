# Bizhy-Bizhy («Біжи-біжи»)

Нескінченна 3D дорога-пригода для дітей 3–7 років без програшу — перша гра студії MGP (MultiGamePlayer).
Воксельний стиль (Crossy Road), три світи — три механіки (GDD v1.1):

| Світ | Механіка | Керування |
|---|---|---|
| Лужок | Біг по 3 доріжках | свайп ←→ доріжка · тап / свайп ↑ стрибок · утримання присід |
| Ліс | Стрибки по клітинках | тап — крок уперед · свайп ←→ убік |
| Пляж | Біг по піску вздовж моря | свайп ←→ доріжка · тап / свайп ↑ стрибок · утримання присід (море декоративне; режим «Хвиля» лишився в коді) |
| Місто-парк | Самокат | як біг: трампліни = довгий політ, рейки = бонус |
| Хмаринки | Невагомість (стрибки) | тап — крок уперед · свайп ←→ убік · вітер зносить |

На станції — **Розвилка**: дитина обирає наступний світ. Мишкою: клік = тап, тягнути = свайп, затиснути = утримання.

Потік: Меню («Біжимо!» / «Герої» / «Мапа» / шестірня → екран батьків через бар'єр) → Мапа (17 рівнів, 5 островів, будь-який відкритий рівень можна грати знову; `young` — одразу рівень) → відлік 3-2-1 → рівень (80–130 с) → фініш із зірками 1–3 → колесо станції → далі / мапа → … → після 17-го рівня — мапа «Усе пройдено! Грай знову» → герой іде спати (таймер сесії) → меню.

**Герої й крамниця:** карусель героїв; кнопка «Крамниця» відкриває 5 вкладок-слотів (капелюшок · окуляри · шарфик · спинка · слід). Предмети показані картинками (воксель спереду) з ціною в зірочках, без назв (назва — у підказці). Тап — приміряти безплатно; куплене одягається одразу (зелена рамка); не куплене — велика кнопка «★ N» купує за зірочки. Дані — `data/shop.json`, моделі — `data/voxels/`.

Керування одночасно трьома способами: свайпи будь-де; кнопки-стрілки знизу (увімкнені для `young`, налаштування `arrows`); джойстик під пальцем (`joystick`). Мишкою: клік = тап, тягнути = свайп/джойстик, затиснути = присід.

**Дебаг (тільки з редактора):** `1–5` — біом на льоту · `L` — наступний рівень · `S` — фініш зараз · `M` — мапа · `W` — 3↔7 доріжок · `F` — веселка · `D` — друг · `Q` — завдання виконано.

**Шрифт (необов'язково, але гарно):** покласти будь-який дитячий TTF як `assets/fonts/kenney_mini_square.ttf` — UI підхопить сам. У сусідньому демо він уже є (CC0):
```
mkdir -p assets/fonts && cp ../../2d-platformer-demo/gui/kenney_mini_square.ttf assets/fonts/
```

## Вимоги

- Godot 4.7 (стабільна версія двигуна; редактор і CI мають збігатися).

## Як відкрити

1. Встанови Godot 4.7.
2. Відкрий цю папку як проєкт (`project.godot`).
3. Запусти сцену `res://src/run3d/run3d.tscn` (або натисни F5 — вона встановлена як головна).

## Як запускати тести

Тести написані під **GUT** (Gut Unit Test) для Godot 4.

1. У редакторі: AssetLib → знайти "Gut" → Download → Install у `addons/gut`.
2. **Закомітити** встановлену папку `addons/gut` у репозиторій (щоб CI міг її використати).
3. Запуск:
   - З редактора: панель GUT (внизу, після встановлення плагіна) → Run All.
   - З командного рядка:
     ```
     godot --headless -s addons/gut/gut_cmdln.gd -gconfig=tests/.gutconfig.json -gexit
     ```

CI (`.github/workflows/ci.yml`) запускає ці ж тести на кожен push і PR.

## Карта папок

- `addons/mgp_core/` — спільний фреймворк (autoload-сервіси, використовуються в усіх іграх MGP):
  - `Events` — глобальна шина подій;
  - `SaveService` — збереження прогресу;
  - `Stats` — локальна статистика;
  - `AgeAdapt` — авто-підбір віку/складності за поведінкою дитини;
  - `SessionTimer` — таймер сесії (попередження і м'яке завершення);
  - `ParentGate` — батьківський бар'єр (утримання кнопки / приклад);
  - `AudioMgr` — керування звуком;
  - `Ads` — заглушка сервісу реклами;
  - `Purchase` — заглушка сервісу покупок;
  - `voxel/VoxelBuilder` — JSON-сітка вокселів → меш (герої, перешкоди, декор).
- `data/` — усі налаштування гри. Нічого з цього не хардкодиться в коді:
  - `profiles.json` — young/mid/older: швидкість, перешкоди, доступні світи, двері Розвилки;
  - `worlds/*.json` — світ = механіка (`mode`), палітра, камера, перешкоди;
  - `events.json` — міні-події з вагами за профілем; `quests.json` — мінізавдання;
  - `shop.json` — крамниця: предмети за слотами (hat/face/neck/back/trail), ціни в зірочках, воксель або колір сліду;
  - `voxels/*.json` — воксельні моделі (шари знизу вгору, символи = палітра).
- `src/run3d/` — геймплей: `run3d.gd` (стани MENU/HEROES/COUNTDOWN/RUN/STATION/SLEEP, жести, Розвилка), `hero3d.gd` (герой: частини, міміка, тінь), `hero_select.gd` (карусель героїв + крамниця), `shop.gd` (каталог/покупка/одягання, `hats.gd` — обгортка для капелюшків), `track.gd`, `spawner3d.gd` (перешкоди/зірочки/зіткнення без фізики), `event_spawner.gd`, `rainbow3d.gd`, `fx.gd` (частинки), `seasons.gd`, `camera_rig.gd`, `modes/` (run / hop / slide), `gestures.gd`.
- `src/ui/` — інтерфейс, три шари:
  - **екрани** — `hud.gd`, `menu.gd`, `map_screen.gd` (мапа з островами, хвилями й хмаринками), `wheel.gd`, `controls.gd`; вони компонують готові віджети, а не малюють самі;
  - `theme/` — вигляд: `palette.gd` (**єдине джерело кольорів**: шкала → ролі → набори) і `ui_kit.gd` (кнопки, заголовки, пружини, шрифт);
  - `components/` — самостійні віджети: `item_strip.gd` (стрічка предметів із гортанням), `heart_icon.gd`, `pickup_icon.gd`, `pickup_bar.gd`, `check_icon.gd`, `hero_marker.gd`, `price_badge.gd`, `lock_icon.gd`, `stick_view.gd` і `icons.gd` (бібліотека намальованих іконок; `VoxelIcon` — картинка предмета з вокселя).

  **Кольори.** Літерала `"#RRGGBB"` у коді бути не повинно — беріть роль із `Palette` (`Palette.BTN_PRIMARY`, `Palette.STAR`, `Palette.WORLD_GROUND`). Кольори з `data/*.json` читайте через `Palette.of(значення, ЗАПАСНИЙ_ТОКЕН)`. Це стереже `tests/test_palette.gd`.
- `tests/` — тести GUT.
- `tools/perf/` — замірник продуктивності (`godot res://tools/perf/perf.tscn`), не частина гри.
- `docs/` — документація: [CHANGELOG](docs/CHANGELOG.md), [задачі](docs/TASKS.md), [збірка](docs/EXPORT.md),
  а також дві серії датованих заходів — [оптимізація](docs/optimisation/) і [код-рев'ю](docs/review/).
  Конвенція серій (ID знахідок, чеклисти, статуси) — у [docs/README.md](docs/README.md).
