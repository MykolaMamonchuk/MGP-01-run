# Інструменти й правила для агентів

Цей файл — про те, ЯК тут працювати, щоб не повторювати помилок, які вже коштували днів.
Перед задачею читати [MEMORY.md](MEMORY.md); тут — стисла шпаргалка з інструментів.

`godot` **не в PATH**: `/Applications/Godot.app/Contents/MacOS/Godot`.
Blender: `/Applications/Blender.app/Contents/MacOS/Blender`.

## Найважливіше правило: спершу порахуй, потім подивись, і лише потім міряй

Мерехтіння на краю дороги шукали два дні. Причина була арифметична —
`road_width() = смуги × 1,0 + 0,2`, а плитка вкриває рівно `смуги × 1,0`, тож 0,10 м полотна
лишалось відкритим, і трава прикривала його через раз. П'ять хвилин із калькулятором давали
відповідь у перший день.

Порядок дій, коли «щось не так із виглядом»:

1. **Порахувати геометрію.** Що з чим межує, з яким зазором, на якій висоті. Числа з коду, не
   з припущень.
2. **Подивитись на пікселі.** Два-три сусідні кадри, кроп, збільшення. Не на весь кадр —
   на місце.
3. **Аж тоді міряти.** І перш ніж вірити метриці — перевірити її на завідомо зіпсованому
   випадку. Метрика, що не спіймала відому поломку, зелена й не стереже нічого.

## Знімки живої гри

```bash
G=/Applications/Godot.app/Contents/MacOS/Godot
OUT=/tmp/probe STAGE=level LEVEL=1 FRAMES=400 RESET=1 PROFILE=older GAME_SEED=20260917 \
  $G --path . --fixed-fps 60 res://tools/probe/probe.tscn
```

- **БЕЗ `--headless`** — інакше 2D не малюється й UI на знімку не буде.
- **`--fixed-fps 60` обов'язковий** для будь-якої сцени, що пише файли в циклі кадрів:
  збереження PNG коштує сотні мілісекунд, і без фіксованої дельти ефект старіє на секунду за
  вісім кадрів.
- **`GAME_SEED` + `RESET=1` + `PROFILE=`** — без них два прогони не збігаються (заміряно:
  37% різних пікселів), і будь-яке «до/після» безглузде.
- Пише `probe.json` (геометрія всіх Control'ів, лічильники, **`decor_cost`** — розкладка
  декору по шарах) і `frame.png`.
- `PAUSE=1 BURST=8` — серія кадрів на паузі. **Межа приладу:** при нерухомій камері
  z-fighting і різниця між рядами не проявляються взагалі, тож «на паузі нічого не
  змінюється» НЕ означає «все гаразд».

| інструмент | для чого |
|---|---|
| `tools/flicker_zoom.py a.png b.png c.png` | куди дивитись, коли «десь мигтить». **Три кадри**, не два: з двома в топ потрапляє просто рух |
| `src/debug/chunk_shot.tscn` | знімок чанка рівня зі світом-орієнтиром, без редактора |
| `src/debug/shatter_shot.tscn` | знімок розбиття предмета покадрово |
| `tools/prop_sheet.py` | усі моделі гри на одному аркуші, підписані вагою |
| `tools/prop_similarity.py` | схожість обробленої моделі з вихідником, у відсотках |

## Моделі

Конвеєр і налаштування генератора — [tasks/meshy.md](tasks/meshy.md). Стисло:

- вихідники лежать у `docs/refs/incoming/<назва>/` (поза git, не імпортуються);
- **брати модель звідти, а не з `assets/props/`**: там уже чиєсь спрощення;
- `tools/prop_bake.py` — ретопологія із запіканням (рельєф із геометрії в текстуру);
  `--shape sphere` для кулястих форм (кущ, крона);
- `tools/prop_prepare.py --weld --tris N --matte --tex-size 1024` — коли рельєфу нема;
- `tools/prop_budget_search.py` — скільки граней можна зняти, поки модель ціла;
- стеля — `tests/test_prop_budget.gd`. Справжня ціна моделі — `decor_cost` у пробі:
  граней × скільки копій ВИДНО (паркан на 899 граней коштує 70 тисяч, бо їх 78).

## Рівні

Рівень — тека `levels/level_XX/` з чанками по 150 м. Маркери лежать у ЛОКАЛЬНИХ метрах, зсув
чанка тримає корінь (`LevelLayout.z_offset_m`). Плоскі `levels/level_XX.tscn` застаріли — не
чіпати.

У редакторі чанк показує світ-орієнтир: дорогу за кількістю доріжок цього рівня, узбіччя,
канал із водою, стінки берега, поручні й містки. Малює `LevelLayout`, у гру нічого з цього
не потрапляє.

## Межі

Установку мосту MCP, запуск гри з ним і правку власних дозволів дозвільний шар Claude Code
блокує навмисно — це робить людина. Обхід іншим інструментом теж обхід. Деталі — [MCP.md](MCP.md).

Ніколи не вмикати `GODOT_MCP_DISABLE_SAFETY`, `GODOT_MCP_ALLOW_UNSAFE`,
`GODOT_MCP_UNRESTRICTED`: разом вони знімають пісочницю GDScript.
