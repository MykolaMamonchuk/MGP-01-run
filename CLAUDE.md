## Тести

`godot` **не в PATH**. Повний набір — 454 тести, ~23 с:

```bash
G=/Applications/Godot.app/Contents/MacOS/Godot
$G --headless -s addons/gut/gut_cmdln.gd -gdir=res://tests/ -gexit     # усе
$G --headless -s addons/gut/gut_cmdln.gd -gtest=res://tests/test_safe_area.gd -gexit   # один файл, 2 с
```

Правка, що чіпає вигляд або розстановку, без тесту не вважається зробленою.

## Вигляд перевіряємо числами, не оком

Скіл `visual-check` — метод. Інструмент — [`tools/probe/`](tools/README.md): запускає гру
у справжньому вікні (**без** `--headless`, інакше 2D не малюється) і дає JSON з геометрією
всіх Control'ів плюс кадр з інтерфейсом.

Заміри «до/після» — лише з контрольним прогоном і по два рази на варіант; фіксуй `RESET=1`
і `PROFILE=`, інакше різні прогони йдуть із різною швидкістю і число бреше. Подробиці —
перший запис у memory bank.
